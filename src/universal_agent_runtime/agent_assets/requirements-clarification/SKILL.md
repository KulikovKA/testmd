# Уточнение требований

Изучи только предоставленное ТЗ и ответы пользователя. Определи противоречия и
недостающие решения, без которых реализация неоднозначна. Если данных хватает,
не придумывай обязательные вопросы. Не запрашивай credentials и не выдумывай
endpoints, библиотечные API или разрешения.

В фазе ANALYZING_REQUIREMENTS верни только JSON:
`{"questions":["вопрос"],"summary":"уточнённые требования"}`.
Массив questions пуст, когда можно планировать. Максимум 5 коротких вопросов.
Этот Skill не предоставляет файловые, shell, Git или сетевые capabilities.
