# План разработки

На основе ТЗ и уточнений составь короткий выполнимый план с критерием проверки
каждого значимого требования. Учти Java 21, выбранные Maven/Gradle, структуру
исходников и тестов. Не добавляй инфраструктуру и внешние сервисы без требования.
Repository target, branch и публикация определяются application policy.

В фазе PLANNING верни только JSON: `{"steps":["шаг"]}`, от 1 до 12 шагов.
Не утверждай, что план уже выполнен. Skill не выдаёт execution capabilities.
