# Руководство по моделям Codex

Этот файл содержит рекомендательные метаданные для пользователя при выборе модели Codex между задачами. Он не является конфигурацией приложения и не должен читаться Universal Agent Runtime или быть с ним связан.

Только пользователь изменяет модель Codex или уровень рассуждений. Агент может рекомендовать настройку, но не должен менять её автоматически.

| Профиль работы | Рекомендуемая модель | Рекомендуемый уровень рассуждений | Запасной вариант |
|---|---|---|---|
| Архитектура или сложное проектирование | GPT-6 Astra | XHigh | Не предписан |
| Обычная реализация | GPT-5.6 Terra | Medium | Не предписан |
| Реализация с архитектурными последствиями | GPT-6 Astra | XHigh | Не предписан |
| Сложная интеграция или отладка | GPT-6 Astra | XHigh | Не предписан |
| Самое сложное исследование инфраструктуры или E2E | GPT-6 Astra | XHigh | Не предписан |

Используйте Luna для небольших механических изменений, документации, форматирования и простых изолированных правок.

Max reasoning не является значением по умолчанию ни для одной задачи. Используйте его вручную, только если задачу блокирует сложный дефект, High/XHigh не выявил причину, существует сложная многокомпонентная проблема либо требуется финальное глубокое исследование сбоя архитектуры/E2E.

Авторитетная рекомендация для конкретной задачи зафиксирована в `TASKS.md`. Рекомендации никогда не активируют задачу.
